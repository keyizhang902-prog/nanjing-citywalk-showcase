# 南京水文化 Citywalk 小程序 · 公开展示版

围绕南京水文化的微信小程序界面展示，包含主题入口、路线条件页面、地图界面、文化知识图谱和评价页面。

此仓库只公开页面结构、样式和演示交互。路线生成、路网分析、定位导航、外部数据请求与评分存储没有接入；操作相应按钮会显示展示版提示。知识图谱可以展开浏览。完整业务实现保留在本地私有源码中。

## 查看界面

使用微信开发者工具导入仓库根目录。默认使用 touristappid，供无真实 AppID 的界面预览；需要使用自己的 AppID 时，在本地修改配置。不需要安装依赖，不需要密钥或云环境。

页面在模拟器和真机上的样式需要按所用开发者工具版本检查。
